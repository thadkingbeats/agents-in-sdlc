Explore o GitHub Copilot ao longo do ciclo de vida de desenvolvimento de software com cenários realistas, um aplicativo completo e um backlog compartilhado. Trabalhe de forma iterativa para planejar alterações, criar código, testar o comportamento, revisar pull requests e gerenciar tarefas com agentes.

## Cenário

Você é uma nova pessoa desenvolvedora na Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com tema de desenvolvimento. O backlog da equipe já está registrado como issues do GitHub e pronto para você começar. Ele inclui recursos como filtragem e paginação e melhorias de qualidade, como acessibilidade e padrões de código.

## Escolha seu ambiente

O GitHub Copilot acompanha você no ambiente em que trabalha. Escolha aquele que combina com a forma como deseja desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agentes do GitHub Copilot CLI (interface de linha de comando) no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, o Model Context Protocol (MCP) do Playwright, Agent Merge e comandos de barra.

### [Aplicativo GitHub Copilot][app]

Execute sessões paralelas de agentes, alterne os modos de sessão, colabore em canvases e gerencie issues e pull requests do GitHub pelo aplicativo para desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise as pull requests criadas.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do ambiente de desenvolvimento integrado (IDE).
