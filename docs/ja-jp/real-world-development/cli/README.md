**[GitHub Copilot CLI][about-copilot-cli]** を使うと、ターミナルで GitHub Copilot をエージェント型コーディング アシスタントとして利用できます。コードベースを調べてコードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインから行えるため、グラフィカル エディターに切り替えずに作業を続けられます。

このワークショップでは、Tailspin Toys の開発を一連の流れで進めます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、プロジェクトを確認します。
2. 星評価の小さな変更を加え、転送されたブラウザーでレビューし、最初のプルリクエスト (PR) を手動でマージします。
3. 絞り込みの issue から始め、Plan モードで方針を定め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、絞り込み機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーで絞り込みを確認します。
7. 品質保証 (QA) カスタム エージェントを作成し、要件、テスト範囲、検証の証拠をレビューします。
8. 絞り込み機能の変更全体を確認し、機能 PR に Agent Merge を使用します。
9. コンテキスト、モデル、共有、任意のクラウド委任に使えるスラッシュ コマンドを確認します。

ワークショップでは、星評価と、指示の更新・スキルの更新・QA プロファイル・テストを含む絞り込み機能の、2 つの PR を作成します。絞り込みと品質のワークフローでは、同じ会話とブランチを使って各ツールの内容を積み上げます。

## 前提条件

このワークショップを始める前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランがある GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドラインの基本的な知識

> [!TIP]
> 有料プランを利用していない場合、認証済みの学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使用する場合は、管理者が Copilot CLI を有効にしていることを確認してください。
